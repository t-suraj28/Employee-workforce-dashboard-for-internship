# Employee Data Analytics Project | Power BI

## Project Overview

This project focuses on analysing employee data from a company with approximately 1,500 records. The goal is to understand workforce patterns related to employee experience, salary, attendance, performance, and training.

The project includes data cleaning, exploratory data analysis (EDA), and an interactive Power BI dashboard to present useful information for better business decision-making.

## Project Objectives

- Clean and prepare employee data for analysis.
- Analyse employee information using statistics and charts.
- Explore salary, attendance, performance, and training data.
- Identify trends, patterns, and possible anomalies.
- Develop an interactive Power BI dashboard.
- Generate useful business insights for workforce management.

## Dataset Information

The dataset is organized into five sheets:

| Sheet Name | Description |
|---|---|
| Employees | Employee details and experience |
| Payroll | Salary and compensation information |
| Attendance | Employee attendance records |
| Performance | Employee performance details |
| Training | Employee training and completion records |

**Dataset size:** Approximately 1,500 employee records.

## Tools and Technologies

- **Microsoft Excel:** Data inspection and cleaning
- **Python / SQL:** Optional tools for data analysis
- **Microsoft Power BI:** Data visualization and dashboard development

## Data Cleaning Process

The following cleaning steps were performed:

1. Removed rows containing missing values.
2. Checked data quality for errors and inconsistencies.
3. Verified employee IDs across different sheets.
4. Prepared the cleaned dataset for analysis and visualization.

## Exploratory Data Analysis (EDA)

The analysis focused on the following areas:

- Employee count and experience distribution
- Salary and CTC distribution
- Attendance patterns
- Employee performance
- Training completion

Charts and statistical summaries were used to explore the data and identify useful patterns.

## Power BI Dashboard

An interactive dashboard was developed in Microsoft Power BI to present the analysis visually.

The dashboard includes:

- Total Employees
- Employee Experience Distribution
- CTC Distribution
- Training Completion
- Workforce Patterns

The visualizations make it easier to understand employee information and compare different categories.

## Key Business Insights

The project supports analysis of five important business areas:

1. **Employee Distribution:** Understand workforce size and experience levels.
2. **Salary Analysis:** Examine salary and CTC distribution.
3. **Attendance Monitoring:** Review attendance patterns and potential issues.
4. **Performance Evaluation:** Identify areas for performance improvement.
5. **Training Analysis:** Monitor training completion and identify potential training needs.

These insights can support workforce planning, performance monitoring, and data-driven decision-making.
