## 📊 Task 1

# Employee Workforce Dashboard

This project is an interactive HR analytics dashboard designed to provide a clear overview of an organization's workforce data.

## Key Insights

- Total Employees
- Active Employees
- Average Employee Age
- Department-wise Employee Distribution
- Gender-wise Employee Distribution
- Work Mode Analysis (Hybrid, Remote, Onsite, Client Site)
- Training Completion Status
- Employee Experience Group Analysis

## Dashboard Purpose

The dashboard helps HR teams and management monitor employee demographics, workforce distribution, training participation, and experience levels. It transforms raw employee data into meaningful visual insights for better planning and decision-making.

## Tools Used

- Microsoft Power BI
- Microsoft Excel / CSV Dataset
- Data Cleaning and Data Visualization

## Preview

The dashboard includes KPI cards, bar charts, donut charts, slicers, and summary tables to make HR data easy to understand and analyze.


## 📊 Task 2: Exploratory Data Analysis (EDA)

As part of my Data Analysis Internship at **SWYNEX**, I completed Task 2 by performing Exploratory Data Analysis (EDA) using Microsoft Excel.

### 🎯 Objective
To analyze the cleaned employee dataset, calculate important statistics, identify trends and patterns, and present meaningful insights using Excel.

### 🛠️ Tools & Techniques
- Microsoft Excel
- VLOOKUP for department name mapping
- Descriptive Statistics
- PivotTables
- Charts and Data Visualization

### 🔍 Work Performed
- Added department names to the Employees sheet using VLOOKUP.
- Added department names to the Payroll sheet to support department-wise salary analysis.
- Calculated descriptive statistics related to employee data.
- Created a department-wise employee distribution chart.
- Compared average annual CTC across departments.
- Identified five useful insights related to workforce distribution, salary, performance, attendance, and training.

### 📈 EDA Visualizations

#### 1. Department-wise Employee Distribution
This chart compares the number of employees across different departments and helps identify departments with larger and smaller workforces.



#### 2. Department-wise Average CTC Comparison
This visualization compares average annual CTC across departments and highlights differences in salary levels.
