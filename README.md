# Employee Workforce Dashboard

This project is an interactive HR analytics dashboard designed to provide a clear overview of an organization's workforce data.

## Key Insights

- Total Employees
- Active Employees
- Average Employee Age
- Department-wise Employee Distribution
- Gender-wise Employee Distribution
- Work Mode Analysis (Hybrid, Remote, Onsite, Client Site)
- Training Completion Status
- Employee Experience Group Analysis

## Dashboard Purpose

The dashboard helps HR teams and management monitor employee demographics, workforce distribution, training participation, and experience levels. It transforms raw employee data into meaningful visual insights for better planning and decision-making.

## Tools Used

- Microsoft Power BI
- Microsoft Excel / CSV Dataset
- Data Cleaning and Data Visualization

## Preview

The dashboard includes KPI cards, bar charts, donut charts, slicers, and summary tables to make HR data easy to understand and analyze.
